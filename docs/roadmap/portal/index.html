02The agent layer

An agent that acts, on rails you can audit.

The difference between an assistant that discusses your appointment and one that books it is tool use. Our agent doesn’t improvise against your calendar — it calls a fixed set of our own endpoints, each one authenticated, rate-limited, budget-capped, and written into the evidence graph the moment it fires.

  • Grounded, not remembered. Fees, timings, directions, and preparation instructions come from the clinic’s approved knowledge base — never from the model’s memory.
  • Verified before it acts. Booking tools stay locked until the caller is verified. A failed tool call is read back and confirmed, never guessed past.
  • Escalation is a first-class outcome. Anything clinical, ambiguous, or upset goes to a human with the context attached. That is a success path, not a failure.

04Four ways in, one record out

Voice where it helps. Touch where it’s safer.

A crowded OPD is not a quiet demo room. Relatives answer for patients, three languages collide in one sentence, and the ceiling fan drowns the microphone. Every mode below produces the identical structured output, so a clinic can choose per workflow — or fall back mid-question without losing the session.

Mode 01

Touch-first

Icons, large buttons, short recorded questions. Cheapest, most reliable, and the automatic fallback whenever voice struggles.

Mode 02 · default

Hybrid voice

The patient speaks, the screen shows what was understood, the patient confirms. Interpretation, not open conversation.

Mode 03 · premium

Conversational

Natural realtime speech for phone calls, elderly patients, and follow-ups. Hard-capped per session by design.

Mode 04

Staff-assisted

The nurse asks; the system listens, structures, and flags what’s missing. Often the safest way into a hospital.

06The agentic question

Agentic, without the agent tax.

“Agentic” is doing a great deal of work in this market right now. Here is exactly where we think the value sits and where the fluff starts — because that judgement is the product. We took the capability and refused the runtime.

KeepWhat is genuinely useful

  • Tool use. The agent books, reschedules, and checks status by calling our audited endpoints. Capability, not conversation.
  • Open-domain answers. Patients ask about parking, fasting, and fees. A scripted tree dead-ends; retrieval over clinic-approved content does not.
  • Multi-step orchestration. Call, no answer, WhatsApp, retry tomorrow, stop on opt-out — genuinely worth automating across channels.

RefuseWhat we will not buy into

  • Hosted agent runtimes. A production agent on a managed platform starts around $500–2,000 a month before a single voice minute. That floor alone ends the affordability story for everyone we want to serve.
  • Autonomous loops on clinical data. Determinism, auditability, and cost control are the product. A self-directed loop dissolves all three.
  • Framework lock-in. We already own the session engine, the state machine, and the tool layer. Renting a second one is a tax, not a capability.

Every tool call the model makes is one of our endpoints, logged as evidence, inside our budget cap. The model is a supplier — Google, OpenAI, or whoever wins next quarter — never the architecture.

08India first, by choice

Built for the hardest room. It travels well from there.

We are not building for India because it is a smaller market to start in. We are building here because the Indian OPD imposes constraints — noise, code-switching, low literacy, shared devices, thin bandwidth, and brutal price sensitivity — that most voice products quietly assume away. A system that works at 10 dB signal-to-noise on a ₹6,000 phone is not a limited system. It is a hardened one.

What India forces us to solve

Constraints as a design brief

  • NoiseTouch fallback on every question, short answer windows, confirmation before commit.
  • LanguageCode-switching and proxy speakers as first-class test cases, not edge cases.
  • QueuesTokens and walk-ins modelled properly, alongside timed slots.
  • PriceCost per completed interaction as a headline metric the customer can see.
  • NetworkOffline capture with sync, because camps and rural clinics lose signal.
Why it generalises

The same engine, other markets

  • ContentNew languages and regions are packs and language files, not forks of the product.
  • SchedulingSlot mode is already in the model — Western practices are the easy case, not a rewrite.
  • StandardsFHIR QuestionnaireResponse mapping and adapter framework for EMR integration.
  • ReachWhatsApp is the front door across South Asia, the Gulf, Africa, and Latin America.
  • TrustConsent, retention, residency, and audit built for DPDP — the same shape as GDPR and HIPAA obligations.
09Under the surface
Workflow DSL

Questions as data

Flows are versioned documents, not code. A published version is frozen, and every intake records exactly which version collected it.

Cost router

Cheapest rung first

Touch is free, deterministic parsing is free, a model is called only when the answer is genuinely ambiguous. Budgets stop spend, never capture.

Eval harness

Tested like software

Noisy audio, code-switching, proxy speakers, contradictions, and adversarial medical questions run against every pack before release and every model change.

Degradation

Capture never fails

If every AI provider is down, the kiosk still collects the history by touch. That is a design rule with tests behind it, not a fallback we hope works.

The boundary

We collect, structure, and verify. We do not diagnose.

What the system doesCollects patient-provided information, structures it, flags what staff should look at, and routes it for review. Department suggestions are routing assistance and always require staff confirmation. Red flags go to a human, never back to the patient as advice.
How it is enforcedNot a disclaimer — an architecture. Output schemas have no field for a diagnosis, generated text is template-bound and filtered, and release gates include adversarial tests for medical advice. Consent is a state the session cannot skip.
