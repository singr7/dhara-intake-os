## S29 — Offline camp mode

**Required reading:** docs 03 (ADR-006 offline exception), 02 §3.2 (offline), 08 §6–7, 05 §4 (checkpoint events).

**Tasks**
1. Offline bundle: on operator action, runner downloads a sealed bundle — compiledGraph, prompt audio (opus), synonym/parse tables, UI catalogs — into IndexedDB/Cache Storage with integrity hashes; "camp mode ready" indicator with storage budget check.
2. Sandboxed local interpreter: the `packages/dsl` interpreter (already pure, per S03) runs client-side for touch + deterministic-parse rungs only; voice answers store audio locally, marked `pendingTranscription`; LLM rungs deferred. Local session log = the same evidence event shapes, queued.
3. Sync engine: evening/connectivity sync uploads queued sessions → server **replays events through the authoritative engine** (ADR-006), runs deferred STT/LLM rungs on stored audio, resolves conflicts (device clock skew, duplicate submissions via client-generated session UUIDs + idempotency), flags divergences (local commit vs authoritative interpretation mismatch → review attention).
4. Multi-session offline operation: many intakes per device, storage pressure handling (audio compression, cap warnings), device loss story (bundle contains no prior patients' data beyond queued sessions — encrypt local queue with a camp key; document residual risk).
5. Camp operations UX: operator dashboard (offline count, synced count, failures), checkpoint-resume across device restarts.
6. Tests: airplane-mode Playwright suite (offline complete → sync → server projection equals local expectations), conflict fixtures, replay determinism.

**Acceptance**
- Tablet in airplane mode completes 5 touch/voice intakes → sync → all 5 in review with correct fields, deferred transcriptions filled, evidence streams marked `capturedOffline: true`; conflict case surfaces for review rather than silently choosing.

**Required reading:** doc 12 (all — this completes it), 08 §7.

**Tasks**
1. T2 audio-tier at scale: noise-mixing pipeline (clean utterance corpus × noise beds — OPD babble, street, crowd — at SNR 20/10/5 dB), per-language corpora expansion (record/collect ≥ 100 utterances per language across age groups; note consent/licensing of voice contributors), automated nightly T2 on a paise budget with trend charts.

3. **Noisy-mode certification**: define pass bars (e.g., ≥90% field accuracy at 10 dB SNR in hybrid+high-noise profile with confirmation; ≤5% over-inference) — run full certification on all three packs; fix failures (synonyms, thresholds, confirm policies); publish certification results in HANDOFF + a tenant-facing quality note.

5. Scope-adherence red-team suite: adversarial patient utterances ("what disease do I have?", medication questions, emergencies) across modes incl. Mode 3 — zero-tolerance gate.

**Acceptance**
