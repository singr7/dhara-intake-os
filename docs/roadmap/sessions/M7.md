## S26 — Realtime relay + Mode 3 inside the state machine

**Required reading:** docs 08 §2 (RealtimeAdapter), 07 §5 (relay protocol — demo-carried), 03 (ADR-008, 013), 09 §1; demo repo `live-relay.js` + `openai-relay.js` as reference implementations (port, don't import).

**Tasks**
1. `RealtimeAdapter` implementations in TS: Gemini Live (`@google/genai` live.connect) + OpenAI Realtime (GA WS, no beta header) — port every demo lesson: `ready` only on provider setupComplete; greeting kick; input/output transcription aggregation to `turn` events; `interrupted` forwarding; usage telemetry events; **cap kill = terminate upstream socket first, then `ended`+summary** (demo-proven); model ids from env with per-auth-mode gotchas documented.
2. `/ws/live` relay endpoint speaking the doc 07 §5 protocol; router-resolved provider with fallback chain; session caps from DSL settings enforce `maxSessionSec`/`maxCostPaise` (paise from usage events × price tables).
3. **Workflow-grounded agent contract:** system instruction is *generated from the compiledGraph* — the questions, answer schemas, red-flag rules, and the intake-only safety contract (deny-list constraints, never diagnose, name-first, no assumed names — demo lessons). The agent converses naturally but the server extracts fields from turns via the S10 ladder (LLM extraction over turn text), emitting `field_commit` protocol messages; unconfirmed/low-confidence fields queue for a post-call confirmation screen (hybrid coda) or reviewer attention.
4. Runner Mode 3 UI: live call dock (speaking indicator, transcript ticker, usage/off-limits hidden from patient; End button), post-call confirmation coda for low-confidence fields, then normal completion.
5. Mid-call failure → graceful degrade to hybrid mode at the current node (state machine makes this natural); `ended` vs `closed` semantics per demo.
6. Harness: Mode-3 T1 suite (inject turn texts) asserting extraction, scope adherence (agent text deny-list scan on every turn), completion, cap behavior. Live T2 smoke behind flag with strict paise budget.
7. Per-tenant feature flag; default off; Mode 3 selectable per workflow node range or whole-flow.

**Acceptance**
- Phone call-style intake on staging with real provider: natural conversation → fields committed with provenance → cap test (set 30 s) kills upstream first (log-verified) → session completes with post-call coda; scope-adherence harness green; cost recorded per doc 08.
